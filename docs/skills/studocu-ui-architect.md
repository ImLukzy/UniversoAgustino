# SKILL: Studocu UI Architect
**Cuándo usar:** Siempre que debas diseñar o modificar componentes visuales del frontend.

## Reglas Estrictas:
1. **Minimalismo:** Fondos `bg-white` o `bg-zinc-50`. Sin bordes duros.
2. **Kowalski Motion:** Usa framer-motion con `transition={{ type: "spring", stiffness: 400, damping: 30 }}` en modales, transiciones y hovers.
3. **Tipografía:** Usa `font-display` para los H1/H2. Los textos secundarios siempre en `text-zinc-500`.
4. **Formularios:** Inputs grandes, limpios, redondeados (`rounded-xl`), sin anillos de focus agresivos, solo bordes sutiles o sombras al hacer focus.
